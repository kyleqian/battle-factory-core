## 0. The recipe and the common findings

**Recipe** (`ec1ced427`, `1ad102b5f`): for each move add (1) a `liveMoveAnimationDuration` case (`src/engine/liveMoveAnimation.ts:160+`),
(2) a config case beside the others (~`:355-470`), (3) `(liveField || view.X.species === "…")` on every species gate in the renderer's
branch, `liveSceneOnBattlerArt(view.attacker|target)` for the hard-coded art, `speciesFrontIdleRestOffsetOrZero(species)` for the hard-coded idle
(`1`/`0` constants), and `if (!liveField)` around the move's own hard-coded `drawSendOutHealthbox`/message block, (4) a
`LIVE_MOVE_OPPONENT_SHADOW_ROW` entry (`:93-106`) iff `activation - windowStart + ageOffset >= 0`, (5) retire any move-local age-0 enemy-shadow draw
(the #142 hook draws it), (6) a per-orientation fixture through `liveAdapterFramebuffer.ts`. All 33 renderer branches use that
pattern (a species-pair `throw` after two `species ===` pairs, then hard-coded art + HUD); every gate line is in the table.

Findings that apply to several moves:

1. **Ad-hoc age-0 shadow draws still exist** in Heal Bell (`battleScene.ts:34394-34407`), Mist Ball (`:17591`), Cosmic Power (`:45789-45800`),
   Blizzard (`:16901-16902`), Whirlwind (`:19130-19142`), Swallow (`:21701+`), Pain Split (`:44838+`). Under the live hook these must go
   (Hyper Fang / Swagger / Bulk Up precedent) or they double-draw.
2. **`animationCenter` convention.** Live geometry (`liveMoveAnimation.ts:330-343`) has player `animationCenter` = pic point (+8, clamp 104). Accepted
   Portable configs sometimes use the RAM sprite centre instead (Whirlwind player Butterfree (72,86), Fake Out Makuhita (72,91), Rock Tomb sprite x,y).
   Renderers that read it: only `.x` in Whirlwind (`:19137`), Mist Ball (`:17592`), Blizzard (`:16903`), Swallow (`:21701,21718`), Cosmic Power
   (uses `battlePositionCenter`); both axes in Heal Bell (`:34441`; its fixture already uses the pic-point convention (72,95)/(176,42), so it matches live),
   Knock Off (`:30128-30146`), Meteor Mash (`:46194-46213`), Extreme Speed (`:30324-30325`). Moves with no read are unaffected.
3. **Pic-coords are already in the live art view.** `createBattleCommandFieldArtView(field)[side].coords` = `{width,height,yOffset}` from
   `src/data/gen/mon-pic-coords.json` (`src/engine/battleCommandFieldArt.ts:20-34,69-70`, back table for player, front for opponent) - exactly what

1. **SURF + MUDDY_WATER** (one branch, 63 rentals): pure recipe; proves the idle/art generalisation on the biggest class.

## 4. Open questions

  (the harness assumes `age = row + ageOffset` from the window start).
