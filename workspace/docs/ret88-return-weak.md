- `data/battle_anim_scripts.s:8924-8948`: `Move_RETURN` shares a prefix with every branch (loadspritegfx, `monbg ANIM_DEF_PARTNER`,

  - then ReturnContinue: `waitforvisualfinish`, `clearmonbg`, `blendoff`.

  is `returnPowerLevel` (`liveSpriteOrderHost.ts`).

  `AnimTask_ShakeMon` tasks. ReturnWeak has none. That was the prediction, and it is confirmed at 0 px on the Onix (idle rest) target.
