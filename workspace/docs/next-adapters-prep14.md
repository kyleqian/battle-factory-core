## 6. Papercuts

- `PAPERCUT:` `BattleLab.validate_request` accepts a gender the species cannot have (MILTANK `male`); only `BattleLab.prepare` rejects it, so a bad alternate costs a full mGBA boot (same class as prep12's set-id papercut), ~5 min.
- `PAPERCUT:` `prep13Probe.py` segfaults at interpreter teardown after writing its JSON (the `run-mgba-probe.py` wrapper tolerates this; direct `$PY` calls print `Segmentation fault: 11` per run), ~3 min to realise it is benign.
- `PAPERCUT:` the `Bash` tool in this shell is zsh: unquoted `$VAR` lists are not word-split, so a `sh script $LIST` call passes one argument; use arrays, ~3 min.
- `PAPERCUT:` the probe's spawn logger records a sprite only on a slot's absent-to-present transition, so same-frame slot reuse (Hail: 12 of 34 sprites) is invisible in both the probe and the corpus transition logs; reducer-vs-ROM comparisons are therefore over the observable subset, ~10 min to explain the 22 vs 34 counts.
