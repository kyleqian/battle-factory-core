## Sample read and range rules

- `normal-fixed` (m4a_1.s:313-395; !(channel.type & (CMP | REV)) && (channel.type & FIX))
  - Reads: One signed sample byte per source advance from currentOffset; no interpolation lookahead.
  - Legal target relation: Safety requires 0 <= currentOffset < size and 0 < count <= size - currentOffset; if looping, 0 <= loopStart < size. The retained v3 pre-call states use the stronger count == size - currentOffset invariant.
  - Loop/read extent: Reads [currentOffset, size) then repeats [loopStart, size) until pcmSamplesPerVBlank output samples are mixed or the channel ends.
  - Required physical payload: size
- `normal-linear` (m4a_1.s:396-435; !(channel.type & (CMP | REV)) && !(channel.type & FIX))
  - Reads: Each interpolation state reads a signed pair at source offsets i and i + 1.
  - Legal target relation: Safety requires 0 <= currentOffset < size and 0 < count <= size - currentOffset; if looping, 0 <= loopStart < size. The retained v3 pre-call states use the stronger count == size - currentOffset invariant.
  - Loop/read extent: Uses the same current/loop ranges as normal-fixed, with a one-byte lookahead at the end of each selected range.
  - Required physical payload: size + 1 readable bytes (declared payload plus one physical guard byte)
- `special-reverse` (m4a_1.s:471-666; channel.type & REV)
  - Reads: Reverses the cursor around WaveData.data + size; normal reverse reads decrementing adjacent samples, compressed reverse delegates to the decoder.
  - Legal target relation: Normal reverse requires 0 < currentOffset <= size and a matching remaining-count invariant; compressed reverse additionally requires the decoded-offset rule.
  - Loop/read extent: Loop rebasing still uses WaveData.loopStart; source has no bound check.
  - Required physical payload: normal: size plus any interpolation guard; compressed: physical 33-byte blocks
- `special-compressed` (m4a_1.s:501-614,670-707; (channel.type & (CMP | REV)) && WaveData.type != 0)
  - Reads: SoundMainRAM_Unk2 reads bytes 0..32 of the selected 33-byte block and emits decoded sample offset & 63.
  - Legal target relation: 0 <= decodedOffset < size; physical payload bytes must cover 33 * ceil(size / 64) for arbitrary in-range decoded offsets.
  - Loop/read extent: The loop counter is in decoded samples; a source-complete audit must retain both decoded size and physical encoded allocation length.
  - Required physical payload: 33 * ceil(size / 64)

## Closure boundary

The source branch inventory and the logical target/range proof for all 565 selected direct-channel snapshots at the v3 call boundary are complete. Every retained pre-call snapshot is normal WaveData.type=0 PCM, has a strict current/count relation, and content-matches exactly one pinned ELF WaveData payload; every pre-call linear target has a pinned one-byte ELF guard.

The original SoundMainRAM dereference class is not closed at actual mixer entry. v3 snapshots before six MPlayMain invocations, and ply_note can replace a selected SoundChannel.wav between that snapshot and SoundMainRAM. It also normalizes direct target pointers, so a content match cannot prove the physical storage domain or allocation span of the target actually dereferenced.
