# Skill Swap / `B_SCR_OP_TRYSWAPABILITIES` evidence

This SIDE-lane checkpoint adds no production interpreter, controller, animation, or rendering code.

`tryswapabilities` is opcode `0xDA`: one opcode byte followed by a four-byte little-endian relocation pointer. `Cmd_tryswapabilities` fails by loading that pointer from `PC + 1` when both active abilities are `ABILITY_NONE`, either active ability is `ABILITY_WONDER_GUARD`, or `gMoveResultFlags` already has `MOVE_RESULT_NO_EFFECT`; any single `ABILITY_NONE` paired with a non-none ability is therefore a success case. Success saves the attacker's active `gBattleMons` ability in local `abilityAtk`, exchanges the two active ability bytes, and advances five bytes. It has zero local `Random()` calls and does not write `gLastUsedAbility`.

`EFFECT_SKILL_SWAP` is `attackcanceler → attackstring → ppreduce → accuracycheck → tryswapabilities BattleScript_ButItFailed`; PP is therefore spent before an accuracy/no-effect/command failure. Success then animates, prints `STRINGID_PKMNSWAPPEDABILITIES`, waits, and goes to `MoveEnd`; the pointer failure takes the ordinary `BattleScript_ButItFailed` result-message route. The source move is Psychic, power 0, accuracy 100, PP 10, selected-target, priority 0, Protect- and Mirror-Move-affected.

The command changes only `gBattleMons`' active ability bytes. It performs no HP, status, stage, damage, weather, or entry-hook action, and calls no `AbilityBattleEffects`; an implementation must not synthesize Intimidate, Trace, Forecast, weather, or other switch-in reactions at the moment of the swap. Later ordinary ability consumers see the exchanged active bytes. `Cmd_switchindataupdate` reloads the entering `BattlePokemon` record and derives its ability from source species/ability-number data, so a switch-in replaces a previously swapped active byte; the persistent party record is not mutated by Skill Swap.

`mechanic-skill-swap-girafarig-shuckle-off.json` uses the Level-50 Factory carrier `FRONTIER_MON_GIRAFARIG_1` (set 235: Psybeam, Stomp, Wish, Skill Swap; Petaya Berry; Quiet) as its complete-party player lead, then selects Skill Swap normally. The initial lead abilities are Girafarig Inner Focus (`39`) and Shuckle Sturdy (`5`). At frame 125, current move is Skill Swap (`285`) with PP still 10. At frame 150, PP is 9 and the public active battlers show Girafarig `5` / Shuckle `39`, while the respective persistent party records remain `39` / `5`; the command-window RNG is unchanged at `3034451114`. The slower Shuckle subsequently uses Tackle, so the receipt also demonstrates that the swap itself deals no damage and does not prevent a normal later turn.

The trace captures every five frames through the command window (100–200). Two complete Battle Scene OFF manifests are byte-identical: `1bb13425…54cd241a`; scenario SHA-256 is `aac80633…836dd883`. All six party checksums are valid at every capture. The public manifest cannot expose the script PC, pointer-failure conditions, doubles targeting, or a physical switch cycle; those are source-pinned rather than claimed from this singles receipt.
