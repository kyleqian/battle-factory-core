# Animation-program deferred questions

Same contract as `DEFERRED.md`, scoped to the animation program: a lean
`## D<number> — OPEN:` entry here records a decision the animation
supervisor cannot safely make (mission scope, canonical oracle state,
hard-to-reverse foundations). An open entry blocks the next
`./run-supervisor.sh --lane animation` session by default. A bounded unattended
schedule may preserve it and continue only independent reversible work until
the user resolves it. Main-program deferrals live in `DEFERRED.md` and do not
block animation sessions (and vice versa).
